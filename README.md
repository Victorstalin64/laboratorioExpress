# Laboratorio: Fundamentos de Express — Cooperativa Trans Andes

## Ejecutar
```bash
npm install
npm start
```
Requiere Node 20.11 o superior. Servidor en http://localhost:3000

## Pruebas
Usa `pruebas.http` (extensión REST Client de VS Code), Postman o Thunder Client.
Token para rutas protegidas (header `token`): `terminal2026`
